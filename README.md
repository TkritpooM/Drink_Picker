# Drinks Picker  
**Drinks Picker** คือแอปพลิเคชันแนะนำเครื่องดื่มตามอารมณ์และความรู้สึกของผู้ใช้  
เหมาะสำหรับผู้ที่ไม่รู้จะดื่มอะไรดี หรืออยากค้นพบเมนูใหม่ ๆ ที่เหมาะกับตัวเอง  

## Functions  
- ระบบแบบสอบถาม 5 ข้อ เพื่อวิเคราะห์อารมณ์/ความรู้สึก  
- คำนวณคะแนนเพื่อจัดอันดับหมวดหมู่เครื่องดื่มที่เหมาะสม
- แสดงรายการเครื่องดื่มในหมวดคะแนนสูงสุด
- ดูรายละเอียดเครื่องดื่ม เช่น ส่วนผสม, ประโยชน์, และข้อมูลเพิ่มเติม

## Tools  
- Visual Studio 2022  
- ใช้ภาษา C# ในการเขียน functions ต่าง ๆ  
- ใช้ XAML ในการออกแบบ UI(User Interface)
